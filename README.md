# Smart Parking & Slot Booking Platform

## Short Project Description

Smart Parking & Slot Booking Platform is a full-stack web application that helps users find and reserve parking spaces in advance. It provides real-time parking slot availability, online booking, booking history, and parking management through separate user, parking owner, and admin dashboards.

The system is built using **Spring Boot, MySQL, and cloud deployment** to make parking faster, more convenient, and efficient.
